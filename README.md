# Личный сайт врача-невролога

Одностраничный персональный сайт врача-невролога (к.м.н.), приём взрослых и детей.
Главный акцент — неврология, научная степень, опыт и места приёма. Кинезиология и
остеопатия показаны как дополнительные методы.

**Live:** https://maximusgenius-collab.github.io/Plusha/

## Структура

- `index.html` — вся страница (разделы: геро, о враче, с чем обращаются,
  методы, где принимаю, отзывы, FAQ, контакты) + SEO-метатеги и schema.org.
- `style.css` — стили и дизайн-токены.
- `fonts.css` и `fonts/` — локальные шрифты.
- `privacy.html` — политика конфиденциальности.
- `robots.txt` и `sitemap.xml` — файлы для поисковых систем.
- `img/` — изображения (фото врача, превью для соцсетей).

## Состояние данных

- Основные сведения о враче, научные профили, места работы и места приёма заполнены.
- Публичные копии документов обезличены: скрыты персональные номера, подписи и иные лишние реквизиты.
- Расписание, стоимость и запись намеренно вынесены на сайты клиник.
- Сайт не содержит форм и не собирает медицинские или контактные данные посетителей.
- На сайте нет форм, аналитики, cookies и сторонних трекеров. Яндекс Метрика
  удалена осознанно. Хостинг GitHub Pages сохраняет IP-адреса в технических журналах
  для безопасности; это отдельно описано в политике конфиденциальности.
- Статистика посещаемости сайта сейчас не собирается владельцем. GitHub Insights →
  Traffic показывает посещения репозитория, а не сайта GitHub Pages. Доступность
  можно проверять внешним аптайм-монитором; его настройка отдельно не подтверждена.
- Шрифты (Spectral, Onest, JetBrains Mono) хранятся локально (`fonts/`, `fonts.css`) —
  браузер посетителя не обращается к Google Fonts. Запросы к хостингу при этом остаются.
- Рейтинг и количество отзывов на ПроДокторов рекомендуется проверять раз в квартал.
- Раздел видео временно не публикуется; его можно вернуть после подготовки роликов и описаний.

Выбран домен `yakovenko-nevrolog.ru`, запланирован переезд на Yandex Cloud.
Регистрация домена и готовность хостинга пока не подтверждены. Текущий сайт остаётся
на GitHub Pages; canonical, Open Graph, Schema.org, robots.txt и sitemap.xml нужно
менять только после готовности нового размещения. Аналитику добавлять не планируется.

## Проверка после изменений

- На экранах 320, 390, 768 и 1280 px проверить отсутствие горизонтального скролла,
  видимость кнопки записи, мобильное меню и возврат по логотипу наверх.
- Проверить FAQ, раскрытие документов и публикаций, ссылки клиник и политику.
- Без JavaScript содержание и все документы должны оставаться видимыми.
- С настройкой reduced motion анимация появления должна быть отключена.
- Перед публикацией проверить локальные ссылки, синтаксис JavaScript и `git diff --check`.

Адаптивно, доступно (фокус, prefers-reduced-motion), без шаблонного AI-стиля.
